# Учебный проект «Мини-Склад» (1С:Предприятие 8.3)

Учебная конфигурация для автоматизации складского учёта (Неделя 1 курса КБ99).

## Состав конфигурации
* **Подсистема:** `МиниСклад`
* **Справочники:** `Товары`, `Контрагенты`
* **Документы:** `Поступление`, `Реализация` (с формами и движениями)
* **Регистры накопления:** `ОстаткиТоваров`
